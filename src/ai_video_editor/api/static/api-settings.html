⚙ API Settings

Chọn nhà cung cấp riêng cho Script, Scene Plan, Image và Voice. Provider và model được lưu trong file config/providers.json; có thể bổ sung từ màn hình này. API key không được lưu trong thư mục project.

1 · Provider API Keys

Lưu key trong Windows Credential Manager / OS keyring. Trang web không bao giờ nhận lại key sau khi lưu. Không đưa key vào log hoặc Git.

2 · Danh mục Providers & Models

Thêm nhà cung cấp hỗ trợ giao thức OpenAI-compatible (Responses API). URL phải là HTTPS. API key lưu riêng trong OS keyring. Danh sách model là cấu hình thủ công, không đồng nghĩa API đã xác minh hỗ trợ.

Các provider có sẵn OpenAI và Gemini không thể xóa. Provider tự thêm cần thực sự hỗ trợ API schema tương ứng, đặc biệt với image/audio.

3 · Chọn Provider theo tác vụ

Video API chưa tích hợp; video prompt vẫn copy/export thủ công. Một số model/provider yêu cầu billing hoặc quyền truy cập riêng.
