Hướng dẫn sử dụng AI Video Editor

Quy trình tạo video từ ý tưởng đến MP4 qua giao diện Web UI hoặc dòng lệnh CLI trên Windows/Linux. Hai cách sử dụng chung project và dữ liệu.

Quy trình Web UIQuy trình CLIProvider / APIXử lý lỗi

1 · Quy trình trên Web UI

  1. Dashboard — Chọn hoặc tạo Project. Mỗi project có kịch bản, dữ liệu scene, assets và kết quả render riêng. Mở Dashboard.
  2. API Settings — Chọn Provider/Model cho từng tác vụ. Cấu hình Script, Scene Plan, Image, Audio và nhập API key nếu dùng API có phí. Mở API Settings.
  3. Script Editor — Tạo và duyệt kịch bản. Nhập yêu cầu, bấm Generate Script, kiểm tra/chỉnh thông tin chung và từng scene, Save Changes → Approve Script → Export Brief. Để chỉnh sửa bằng file, dùng Export Script JSON, sửa JSON và Import Script JSON trên Script Editor; sau khi nội dung đổi phải phê duyệt và tạo lại kế hoạch downstream. Mở Script Editor.
  4. Scene Planner — Lên kế hoạch cảnh quay. Bấm Generate Scene Plan, chọn scene bên phải để xem media type, motion, transition, prompt, thời lượng. Save → Approve → Export Asset Brief. Mở Scene Planner.
  5. Asset Workspace — Chuẩn bị media và giọng đọc. Sao chép/xuất prompt để tạo thủ công; hoặc dùng API Image/Voice theo scene hay batch. Chọn scene bằng checkbox, chọn voice, kiểm tra Giới hạn API, xác nhận trước khi tạo. Mở Asset Workspace.
  6. Render Studio — Bind và render. Tải ảnh/video/voice lên nếu cần, Auto-bind → Validate/Approve Manifest → Generate/Approve Editing Plan → Render, theo dõi tiến độ và xem MP4. Mở Render Studio.
Lưu ý chi phí: Copy prompt, chỉnh sửa và duyệt không tự tạo media bằng API. Generate Script, Generate Scene Plan, Generate Image và Generate Voice có thể phát sinh phí, tùy provider/model. Batch cần xác nhận riêng. Giới hạn trong ứng dụng không phải số dư thực tế tại nhà cung cấp.

3 · Quy trình bằng CLI

CLI phù hợp Linux, server cloud, PowerShell và automation. Các lệnh dưới đây dùng project minh họa demo_video; thay bằng ID project thực tế.

A. Tạo project và cấu hình provider

ai-video-editor init demo_video --title "Video Demo"
ai-video-editor provider list
ai-video-editor provider models gemini
ai-video-editor provider key-set gemini
ai-video-editor provider set audio gemini --model gemini-2.5-flash-preview-tts

B. Tạo, duyệt Script và Scene Plan

ai-video-editor agent-script demo_video --request "Tạo video 30 giây về biển, 3 scene, tiếng Việt" --use-provider-settings
ai-video-editor agent-script-status demo_video
ai-video-editor agent-script-approve demo_video
ai-video-editor agent-script-export demo_video
ai-video-editor agent-scene-plan demo_video --configured-provider
ai-video-editor agent-scene-status demo_video
ai-video-editor agent-scene-approve demo_video
ai-video-editor agent-scene-export demo_video

Nếu file đã tồn tại, CLI có thể yêu cầu xác nhận ghi đè. Kiểm tra trạng thái trước khi tạo lại để không mất công việc cũ.

C. Xuất prompt để dùng công cụ bên ngoài hoặc tạo asset bằng API

ai-video-editor agent-asset-prompts demo_video --format markdown --output asset_prompts.md
ai-video-editor asset usage demo_video
ai-video-editor asset limits demo_video --image 100 --audio 100
ai-video-editor asset generate-voice demo_video --scene 001 --voice Kore --auto-bind
ai-video-editor asset batch-image demo_video --scenes 001,002,003 --auto-bind
ai-video-editor asset batch-voice demo_video --all-scenes --voice Kore --auto-bind
ai-video-editor asset auto-bind demo_video

Không có --yes, CLI yêu cầu xác nhận tương tác. Khi tự động hóa và đã chấp thuận chi phí, mới thêm --yes. Chọn Voice chỉ có hiệu lực với provider/model hỗ trợ voice đó.

D. Bind thủ công và dựng video

ai-video-editor agent-init demo_video --brief projects/demo_video/agent_scene_brief.json
ai-video-editor agent-bind demo_video --scene 001 --kind media --file assets/images/scene_001.png
ai-video-editor agent-bind demo_video --scene 001 --kind voice --file assets/audio/scene_001.mp3
ai-video-editor agent-status demo_video
ai-video-editor agent-approve demo_video
ai-video-editor agent-compile demo_video
ai-video-editor plan demo_video
ai-video-editor approve-plan demo_video
ai-video-editor compose demo_video --deep

Các file ví dụ chỉ hợp lệ khi thực sự tồn tại và loại media của scene tương ứng. Với kế hoạch AI đã duyệt, tham khảo ai-video-editor agent-scene-apply demo_video thay cho tạo plan rule-based, sau khi storyboard đã sẵn sàng. Lệnh compose tái sử dụng checkpoint/cache hợp lệ theo Core.

4 · Provider, API key và lựa chọn Voice

Script / Scene Plan

Chọn provider/model trong API Settings. CLI có --use-provider-settings hoặc --configured-provider để dùng cùng định tuyến.

Image / Audio

Chọn provider riêng theo tác vụ. Voice của project được giữ lại cho các lần tạo sau; batch dùng một giọng cho các scene được chọn.

API key được lưu trong OS keyring hoặc lấy từ biến môi trường được hỗ trợ, không đặt vào project JSON hay source. Không chia sẻ key trên ảnh chụp màn hình/log.

5 · Các câu hỏi thường gặp

Generate Voice có đọc image prompt không?

Không. TTS phải dùng narration tiếng Việt của scene. Hãy kiểm tra và nghe thử một scene trước khi chạy batch.

Đã có Script nhưng không chỉnh được Scene Plan?

Script thay đổi làm kế hoạch downstream cũ không còn phù hợp. Lưu và duyệt lại Script, tạo Scene Plan mới rồi duyệt lại các bước liên quan.

Tại sao không thể dùng ảnh thay video clip?

Loại media trong Scene Plan/Manifest phải khớp file được gán. Muốn dùng PNG thay MP4, hãy cập nhật media type và duyệt lại kế hoạch.

Hết lượt Image/Audio?

Vào Asset Workspace, mục 3 · Giới hạn API để tự đặt số lượt/ngày. Hạn mức này chỉ là giới hạn nội bộ; nhà cung cấp API vẫn có giá và quota riêng.

Render chậm, bị timeout hoặc dừng giữa chừng?

Kiểm tra log/checkpoint, giữ nguyên assets và editing plan để Core có cơ hội tái sử dụng cache hợp lệ. GUI có thiết lập Render Timeout; đặt 0 để không giới hạn tổng thời gian tại lớp GUI.

Cần dùng GUI trên Linux không?

CLI chạy trực tiếp trên Linux. GUI chạy localhost bằng ai-video-editor ui nếu đã cài pip install -e '.[ui]'. Không nên công khai cổng GUI ra Internet.
